# Ideias

Coisas que a gente decidiu fazer **depois**, com a decisão já registrada.

Não é backlog e não é lista de desejos. Cada arquivo aqui existe porque a
conversa aconteceu, chegou a uma conclusão, e essa conclusão vai ser esquecida
se não estiver escrita — normalmente junto com o motivo, que é a parte que se
perde primeiro.

O que um arquivo daqui precisa ter:

- **a decisão**, não só o desejo
- **por que foi adiado** — e o que precisa ser verdade pra deixar de ser
- **o que custa esperar**: o que fica barato de fazer depois, e o que fica caro
- **o que muda se a decisão for revertida** — quais arquivos, quais formatos

Quando uma ideia sai daqui pra ser feita, ela vira uma entrada em
[PRIORIDADES.md](../PRIORIDADES.md) e o arquivo aqui some (o git guarda).
